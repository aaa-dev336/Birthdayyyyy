EGNER BIRTHDAY WEBSITE

This is a ready-to-upload static website. No installation or build step is required.

FILES
- index.html — page content
- styles.css — design and responsive layout
- script.js — surprise, confetti, wish picker, and small interactions
- assets/ — all images used by the page

HOW TO OPEN
Double-click index.html.

HOW TO UPLOAD
Upload index.html, styles.css, script.js, and the whole assets folder to the same directory on your hosting service.

HOW TO EDIT THE MESSAGE
Open index.html in any text editor. Search for “Dear Egner” or “Happy birthday” and replace the text between the HTML tags.
